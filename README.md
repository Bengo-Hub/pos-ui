# POS UI

BengoBox point-of-sale UI. Order entry, tables, drawer, platform admin.

## Dev

```bash
pnpm install
pnpm dev
```

## Deploy

Deployed at `https://pos.codevertexitsolutions.com`. CI on push to `main`.

## Push from this folder (own repo)

```bash
# From: pos-service/pos-ui
git remote add origin https://github.com/YOUR_ORG/pos-ui.git
git branch -M main
git push -u origin main
```
